Contributing
------------
To loosely paraphrase a quote from `Gael Varoquaux <http://gael-varoquaux.info/>`_, we want to build tools that will solve 80% of a user's problems. In other words, we want NivLink to be a package comprised of general purpose tools helpful for a broad variety of eyetracking/pupillometry paradigms. 

Before you submit a open an issue or submit a pull request, ask yourself these two questions:
1. Is the tool I have in mind part of preprocessing?
2. Is the tool I have in mind likely to be useful for a variety of experiments?

If the answers to both question are yes, then you should contribute!
